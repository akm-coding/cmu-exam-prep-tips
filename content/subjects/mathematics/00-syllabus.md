# CMU Mathematics exam — official syllabus

## Who takes it

Applicants to ACC, CIE, EESG, IEL, ISCE, IGME, MEPM, ECON, SE and MMIT (Regular Track). It is held in the 09:00 – 12:00 subject-test window. SE applicants take it in the same window as the Software Engineering Aptitude Test, so budget time across both. (For ACC, a minimum of 40% on the CMU Mathematics exam is required; no minimum is published for SE.)

## Topics listed by CMU

1. Logical statements and truth values (True/False)
2. Basic functions: one-to-one and onto
3. Domain and range of functions
4. Graphs of functions
5. Basic properties of polynomial, logarithmic, exponential and trigonometric functions
6. Inverse trigonometric functions
7. 2×2 matrices: basic operations, determinant, solving a system of linear equations

## Suggested study order

Logic → functions (domain/range, one-to-one/onto, graphs) → polynomial, exponential and logarithmic functions → trigonometric and inverse trigonometric functions → 2×2 matrices. Each topic has its own note in this knowledge base.
