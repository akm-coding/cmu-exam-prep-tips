# Software Engineering (SE), CAMT, Chiang Mai University

## About the program

The Bachelor of Science in Software Engineering (International Program) is offered by the College of Arts, Media and Technology (CAMT). It combines computer science, project management and software quality management, and aims to produce software engineers for the global software industry. The curriculum conforms to SEEK (Software Engineering Education Knowledge) standards. Learning is mainly project-based, applying theory to real situations, and includes cooperative education with software companies before graduation.

Career paths: software engineer, programmer / system developer, system analyst and designer, software tester, software operator, software project manager, software architect, business analyst.

## SE admission requirements (2027)

- **Seats:** 25 students
- **Academic qualification:** applicants with education higher than M.6 (or equivalent) are **not** accepted; vocational school diploma holders are **not** accepted.
- **GPA:** no minimum overall GPA. Thai system applicants must have Physics, Chemistry and Mathematics in their transcript. Equivalency (e.g. GED, international) applicants must have Mathematics in their transcript or listed in a standardized test (e.g. AP).
- **English proficiency:** applicants who completed an international program or English-medium school are **not exempt**. Accepted minimum scores: IELTS 5.0; TOEFL PBT/ITP 500, CBT 173, or iBT 61; TOEIC 600; CMU TEGS 65 or CMU IPET 60; CU-TEP 73; TU-GET PBT 600 or CBT 68; Duolingo (DET) 85; GAOKAO English 100. Without one of these, take the CMU English Placement Test.
- **Regular Track exams (CMU EXAM):** Mathematics **and** the Software Engineering Aptitude Test.
- **Special Track:** New SAT (Math + Evidence-Based Reading and Writing) total of at least 800 — no CMU EXAM, interview only.
- **Extra application documents:** none.
- **Tuition:** Thai nationality THB 40,000 per semester; other nationalities THB 60,000 per semester.
- **Rounds:** SE is open in Round 1 (apply NOV 30, 2026 – JAN 13, 2027; exam FEB 8, 2027) and Round 2 (apply MAR 16 – 22, 2027; exam APR 5, 2027).
- **Contact:** interadmission-CAMT@cmu.ac.th, +66-53-920-299 ext. 107. Admission office: ipas_admission@reg.cmu.ac.th, +66 5394 8918.

## Study plan highlights

- **Year 1:** Fundamental English 1 & 2, Computer and Programming, Web User Interface Design and Development, Digital Proficiency for SE, Abstract Data Type and Problem Solving, Introduction to Software Engineering, Computer Organization, Object Oriented Programming, Interactive Web Development.
- **Year 2:** Algorithms Design and Analysis, Database Systems and Database Systems Design, Advanced Programming, Human Factors in Digital Interaction Design, Computational Foundations for Modern Software Development, Operating System and Computer Networks, Computational Programming for Modern Software Development, Object Oriented Analysis and Design, Basic Development and Operations (DevOps), Citizenship.
- **Year 3:** Software Requirement Analysis; Software Design, Architecture and Constructions; Component-Based Software Development; SE Preproject; Artificial Intelligence for Software Engineering; Software Testing and Maintenance; major electives.
- **Year 4:** Ethics and Professionalism for Software Engineers, Software Quality Assurance, Software Engineering Project, then Cooperative Education (9 credits) in the final semester.

These Year 1 topics (computer organization, programming, problem solving) overlap with the aptitude test's "computer basics, software and hardware" part, so studying them early helps both the exam and the first year.
